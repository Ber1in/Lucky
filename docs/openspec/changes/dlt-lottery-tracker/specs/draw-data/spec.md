# Spec Delta

## Purpose

提供大乐透开奖数据的可靠获取、存储与查询，覆盖历史回填、开奖日增量同步、按期查询和规则版本标注，是号码统计与投注核算的数据基础。

## ADDED Requirements

### Requirement: 历史数据回填

系统 SHALL 能从官方开奖接口回填从 07001 期起的全部历史开奖，并且对同一期号重复回填时保持幂等，不产生重复记录。

#### Scenario: 首次回填全部历史

- **WHEN** 系统首次启动且开奖表为空
- **THEN** 系统按分页拉取全部历史期次并写入，最终期数与官方总数一致

#### Scenario: 重复回填不产生重复

- **WHEN** 对已存在的期号再次执行回填
- **THEN** 该期数据被更新或跳过，开奖表中不出现重复期号

### Requirement: 开奖日增量同步

系统 SHALL 在每周一、三、六北京时间 21:35 之后触发增量同步，拉取最新一期；若官方结果尚未发布，则按固定间隔重试，成功写入后停止。

#### Scenario: 开奖日成功更新

- **WHEN** 开奖日 21:35 后官方接口已返回当期结果
- **THEN** 系统写入新期次，并记录本次同步成功

#### Scenario: 结果尚未发布时重试

- **WHEN** 触发时官方接口仍未返回当期结果
- **THEN** 系统在间隔后重试，直到成功或达到最大尝试次数

#### Scenario: 非开奖日不产生新数据

- **WHEN** 在非开奖日触发同步
- **THEN** 系统不写入新期次，同步结果记录为无更新

### Requirement: 同步结果可观测

系统 SHALL 记录每次同步的触发时间、结果、尝试次数和错误信息，供排查使用。

#### Scenario: 同步失败留痕

- **WHEN** 官方接口请求失败或返回异常结构
- **THEN** 系统记录失败原因与尝试次数，且已有开奖数据不受影响

### Requirement: 开奖数据查询

系统 SHALL 提供最新一期、按期号倒序分页的历史列表和单期详情三种查询。

#### Scenario: 查看最新一期

- **WHEN** 用户打开首页
- **THEN** 系统返回期号最大的开奖记录及其奖级明细

#### Scenario: 分页浏览历史

- **WHEN** 用户请求第 N 页历史
- **THEN** 系统按期号倒序返回对应页数据及总期数

#### Scenario: 查询不存在的期号

- **WHEN** 用户请求一个不存在的期号
- **THEN** 系统返回未找到错误

### Requirement: 规则版本标注

系统 SHALL 为 26014 期及以后的开奖标注“七等奖制”；26014 期之前的开奖标注为“历史规则”，仅用于展示，不参与投注核算。

#### Scenario: 七等奖制期次

- **WHEN** 查询 26014 期及之后的开奖
- **THEN** 该期标注为七等奖制

#### Scenario: 历史规则期次

- **WHEN** 查询 26013 期及之前的开奖
- **THEN** 该期标注为“历史规则”，并允许查看开奖号码与接口返回的奖级明细

### Requirement: 奖级明细以接口为准

系统 SHALL 保存每期奖级明细（奖级名称、单注奖金、中奖注数），奖金金额以当次接口返回为准，不硬编码固定奖金额。

#### Scenario: 奖池达到阈值时固定奖上浮

- **WHEN** 某期奖池达到 8 亿元及以上
- **THEN** 系统保存的三至七等奖单注奖金为接口返回的上浮金额

#### Scenario: 派奖期保留额外奖级

- **WHEN** 某期存在派奖产生的额外奖级条目
- **THEN** 系统按奖级名称保留这些条目，不假设固定条目数
